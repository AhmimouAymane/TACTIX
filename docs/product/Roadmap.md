# 1. Objective

The Roadmap defines the phased evolution of TACTIX from pre-launch preparation to becoming the leading football platform in Africa.

---

# 2. Roadmap Principles

- Each phase builds on the previous
- Core fantasy gameplay is always stable
- Expansion is modular, never a redesign
- User feedback shapes prioritization
- Data and metrics drive decisions
- No phase ships without quality gates

---

# 3. Phase 0 — Pre-Launch

## Goals

- Validate demand with a private beta
- Collect early feedback
- Validate the data provider
- Complete security review
- Prepare store listings

## Deliverables

- Beta app (Android)
- Core backend
- Admin dashboard
- Beta community
- Feedback pipeline

## Exit Criteria

- Beta signups: 500+
- Crash-free sessions: 99.5%+
- Critical defects: 0

---

# 4. Phase 1 — Botola Fantasy (Version 1)

## Scope

- Full fantasy season
- Registration and authentication
- Team creation and management
- Transfers and captain selection
- Live scoring
- Private and public leagues
- Rankings
- Notifications
- Match Center
- Player and club discovery
- Gamification
- Premium subscriptions

## Launch Platforms

Android

iOS

## Duration

One full Botola Pro season (30 gameweeks).

## Exit Criteria

- 50,000 registered users
- 15,000 MAU
- 5% premium conversion
- 4.7+ store rating
- 99.8% crash-free sessions

# 5. Phase 2 — Expansion

## Goals

- Expand competitions
- Deepen AI
- Add competitive modes

## Features

- Fantasy CAF Champions League
- Fantasy CAF Confederation Cup
- Improved AI recommendations
- Fantasy Cup (knockout)
- Draft mode
- Enhanced player statistics

## Exit Criteria

- Multi-competition support stable
- Fantasy Cup engagement: 30%+ of MAU

# 11. Risks

| Risk | Mitigation |
|---|---|
| Data provider gaps | Contracted provider + manual override |
| Low adoption | Beta community, referrals, marketing |
| Competition | Focus on Botola, premium quality |
| Licensing | Early league partnership talks |
| Scaling | Cloud infrastructure, load testing |

# 12. Success Metrics

Tracked per phase:

- User growth
- Engagement
- Retention
- Revenue
- Feature adoption
- Store ratings

---

# 13. Acceptance Criteria

✓ Each phase exits with defined metrics met.

✓ Core gameplay remains stable across phases.

✓ Expansion happens without redesign.

✓ User feedback is incorporated.

✓ Revenue targets are tracked.
