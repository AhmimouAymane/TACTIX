# 1. Objective

The League System enables managers to compete together in private and public leagues.

It supports seasonal competition between friends, coworkers, universities, and communities.

---

# 2. League Principles

- Leagues never affect the scoring engine
- League rankings derive from total fantasy points
- Owners control league configuration
- Membership is voluntary
- Fair play is enforced

---

# 3. League Types

## Private Leagues

- Created by a manager (owner)
- Requires an invitation or code to join
- Owner controls settings

---

## Public Leagues

- Visible to all managers
- Anyone can join
- Open for the season

---

## Auto-Created Leagues

Future: leagues generated by region, club, or language.

---

# 4. League Creation

## Requirements

To create a league:

- The manager must have a valid squad
- The manager becomes the owner

## League Name

- 3-50 characters
- No offensive words
- Unique per season (case-insensitive)

## League Code

Each league has a unique join code.

- 8 characters
- Alphanumeric
- Regenerable by owner

---

# 5. Visibility

## Private League

- Not visible in search
- Join via invitation or code only

## Public League

- Visible in search
- Anyone can join

# 7. League Capacity

## Limits

Private league maximum:

100 members

Public league maximum:

100 members

## Full League

Join requests are rejected when full.

---

# 8. League Owner Permissions

The owner can:

- Rename the league
- Regenerate the join code
- Invite members
- Remove members
- Promote members to co-owner (future)
- Transfer ownership
- Disband the league
- Configure settings
- Post announcements

---

## Owner Transfer

Ownership transfers to a co-owner or member.

A disbanded league cannot be restored.

---

# 9. Member Permissions

Members can:

- View the leaderboard
- View league info
- Post in announcements (if enabled)
- Invite others (if enabled)
- Leave the league

Members cannot:

- Rename the league
- Remove other members
- Change settings

# 19. Rivalries

## Concept

- A rivalry badge is shown

# 21. Moderation

## Reporting

Members can report:

- Offensive league names
- Abusive announcements
- Misconduct

## Owner Moderation

Owners can:

- Remove members
- Mute members

## Admin Moderation

Admins can review reported leagues.

Actions:

- Warning
- Remove league
- Ban organizer
